# 對外宣傳與社群素材歸檔 (`docs/promo-archive/`)

> [!IMPORTANT]
> **非執行期資產・AI Agent 日常開發請勿掃描或讀取**
> - 本目錄專門歸檔對外社群貼文、功能展示截圖與歷代宣傳影片母帶，**絕不進入遊戲執行期，亦不會被打包進 `dist/`**。
> - 遊戲執行期載入之資產位於根目錄 `assets/` 與 `data/`。
> - 線上玩家百科（`yanlin-gta.com/wiki/`）首頁實際載入的現行 100 秒宣傳片與封面海報已獨立配置於 `wiki/media/promo.mp4` 與 `wiki/media/promo-poster.jpg`。

## 目錄內容

| 子目錄 | 說明 |
| :--- | :--- |
| `promo/` | 歷代宣傳片成品與無配樂母帶（`yanlin-demo-30s.mp4`、`yanlin-promo-53s.mp4`、`yanlin-promo-58s-v2.mp4` 與其無配樂版、封面，`yanlin-promo-100s-v3-nobgm.mp4`）。錄製與剪輯工具見 [`tools/promo/README.md`](../../tools/promo/README.md)。 |
| `threads/` | 對外社群行銷貼文文案與配圖歸檔（100 篇系列貼文）。 |
| `parked-scooters/` | 路邊多車型停放機車功能展示截圖。 |
