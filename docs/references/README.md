# 建模原材料與圖資備份 (`docs/references/`)

本資料夾用於**保存與備份**本專案 3D 建模過程中所使用的參考素材與原始圖資，包括但不限於：

- 建築室內平面圖（`floorplans/`）
- 校園建築與街景測繪圖資、配置參考檔
- 人物建模與服飾造型之原始參考素材備份

## 重要邊界規則

1. **非遊戲執行期資產**：本資料夾內的任何檔案**不會**被遊戲程式直接載入，也**不會**被 Vite 打包進 `dist/`。
2. **遊戲實際會吃到的素材請放對位置**：
   - 貼圖、頭像、UI 圖示、音效與配樂 → `assets/`
   - 遊戲地理資料與 NPC 名冊 → `data/`
3. **隱私與大型本機檔注意**：涉及個人隱私的參考照片或未經壓縮的龐大影片原檔，應留在本機忽略路徑（如 `assets/private/`、`tools/npc-dashboard/photos/`），切勿誤傳至 Git。

## 現有子目錄

- [`floorplans/`](floorplans/README.md)：由 `node tools/floorplan/make.mjs` 依建模程式產生的可進入室內建築 SVG 平面圖（力行宿舍、學生活動中心等）。
