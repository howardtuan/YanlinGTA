# v3 宣傳片設計 spec（1:40，video-shotcraft 共同創作模式）

成片：`tools/promo/video` 的 `YanlinPromo3`（`src/Promo3.tsx`、`src/scenes3.tsx`），1920×1080、30 fps、3010 格。
素材：`tools/promo/shots_v3.sh`（錄影）＋ `tools/promo/v3_lib.sh`（共用函式）。

## 已確認的需求

| 需求 | 執行方式 |
|---|---|
| 介紹整個專案的遊戲宣傳片，最長 2 分鐘 | 1:40，七段：校園 → 周邊 → 手機 → 電腦 → NPC 隱藏支線 → Wiki → 片尾 |
| 勞大不出現、也不註記 | 不拍直升機／空投／呼叫載具／訊息列表；Wiki 不拍「最新消息」頁 |
| 資訊多時用橫向六宮格 | 周邊、電腦用 3×2 宮格，手機用一排六支，進場方式各不相同 |
| NPC 段：說明是隱藏 NPC 任務彩蛋、改編自真實事件；一位 NPC 一個任務；不放女友角色 | 說明卡 5 秒（隱藏 NPC 任務彩蛋／每一段任務都改編自彥霖和同學們真實發生過的事／把大學時期的酸甜苦辣放進遊戲裡和你分享）→ 2×2 四宮格 8 秒：吱吱武嶺跑山受傷、品漢堡找車、劍玉班費失竊案、霍華德 Two Sum |
| 配樂用情境音樂 | 只用遊戲自己的 scene-day / market / timed / night / ending；來電時音樂停掉 |
| 遊戲介紹完花幾秒介紹 Wiki | 9 秒：角色介紹頁捲動 → 頁面瀑布牆 → 停在支線頁的吱吱任務 |
| 騎車不寫車子型號 | 字幕為「騎上機車，衝出校門」 |
| 資管系館拍正面 | 北面「資訊管理學系」直立招牌 |
| 最後一幕放遊戲與 Wiki 網址 | yanlin-gta.com、yanlin-gta.com/wiki，停留 5 秒 |
| 電腦桌面用預設天藍色背景 | `director.js` 的 `#promoWall` 把桌布蓋成遊戲預設的藍色漸層（只影響錄影） |

視覺 token 沿用遊戲 UI（`src/theme.ts`：accent #ffd23f、red #e8323c、ink #0d1020、Noto Sans TC）。

- 第 3 鏡：遊戲大地圖是傾斜平板畫面，不適合飛點，改成推近後快切四個地點。
- 第 7 鏡：漢堡車改成中原夜市（漢堡車是品漢的私人車，手機 App 段已經有）。
